# Gen-AI Video Analyzer (demo)

Transcribe a meeting or video (Whisper), get a summary, action items and decisions (Gemini), and chat with it using hybrid retrieval (embeddings + BM25).

You need a free Gemini API key from https://aistudio.google.com. Try the built-in sample meeting first; uploads are limited to 10 minutes.

Source code, tests and the retrieval evaluation: https://github.com/shushant11/gen-ai-video-analyzer
